1. ¿Qué es Python?
🐍

Explicación básica y elementos iniciales

Para qué sirve y qué funciones usarás

▾

Python es un lenguaje de programación: un idioma que usamos para darle instrucciones a un computador. Escribimos esas órdenes en un archivo de texto con extensión .py y el computador las ejecuta una por una, de arriba hacia abajo.

Es uno de los lenguajes más usados del mundo porque su forma de escribir es clara y parecida al inglés: se lee casi como una receta. Por eso es ideal para empezar — te concentras en resolver el problema y no en reglas de escritura complicadas.

🚀 ¿Para qué se usa en el mundo real?

Automatizar tareas repetitivas, analizar datos y generar reportes, crear páginas web y aplicaciones, inteligencia artificial y chatbots, videojuegos sencillos y soluciones para empresas y colegios. Plataformas como YouTube, Instagram, Netflix y Spotify usan Python en parte de sus sistemas.

👋 Tu primer programa

Lo más simple es mostrar un mensaje en pantalla con la función print():

# mi_primer_programa.py
print("¡Hola! Estoy aprendiendo Python.")
print("Programa: Sistemas Teleinformáticos")

Al ejecutarlo, el computador escribe:

¡Hola! Estoy aprendiendo Python.
Programa: Sistemas Teleinformáticos
💡 Tres reglas para no equivocarte

1. Python distingue mayúsculas de minúsculas: print funciona, Print da error.   2. El texto va siempre entre comillas: "Hola".   3. La indentación (los espacios al inicio de una línea) es obligatoria e indica qué instrucciones pertenecen a un bloque.

2. Tipos de variables en Python
📦

Tipos de datos

Texto, números, lógicos y colecciones

▾

Una variable es un espacio en memoria donde se guarda información. En Python no es necesario escribir el tipo de dato antes de crear la variable, porque Python lo identifica según el valor asignado.

▶ Pulsa "probar" y verás a Python crear cada tipo de variable con su valor y su tipo (o se ejecutan en cascada al aparecer):

strTexto o cadena de caracteres.
intNúmero entero.
floatNúmero decimal.
boolValor lógico: True o False.
listLista ordenada y modificable.
tupleColección ordenada que no se modifica.
dictDiccionario con clave y valor.
setConjunto sin datos repetidos.
NoneRepresenta ausencia de valor.
📌 Recomendación

Antes de las condicionales, diferencia entre texto, número entero, número decimal y valor lógico: los errores más comunes ocurren al comparar datos de tipos diferentes.

3. Operadores y condicionales
🔎

Comparación, lógicos y tipos de condicional

Para que el programa tome decisiones

▾

Las condicionales permiten que un programa tome decisiones: ejecutan una acción solo si se cumple una condición.

Operadores de comparación (dan True o False) — pulsa "probar"

==Igual a
!=Diferente de
>Mayor que
<Menor que
>=Mayor o igual que
<=Menor o igual que

Operadores lógicos (combinan condiciones) — pulsa "probar"

andTodas las condiciones deben cumplirse.
orAl menos una condición debe cumplirse.
notNiega una condición.

Tipos de condicionales

TipoCuándo se usa
ifCuando solo se necesita validar una condición.
if - elseCuando hay dos caminos posibles.
if - elif - elseCuando hay varias opciones.
Condicional anidadaCuando una condición depende de otra.
Condición compuestaCuando se combinan condiciones con and/or.
Condicional ternariaPara una decisión corta en una línea.
match - casePara evaluar varias opciones de forma ordenada.
⚠ Nota sobre match-case

La estructura match-case está disponible desde Python 3.10. Si el computador usa una versión anterior, se puede reemplazar por if, elif y else.

3Nota final con if y else▾
▶ Abrir compilador Python en línea (Programiz) ↗ 📌 Escribe y ejecuta tu reto aquí si no tienes el programa instalado.

Objetivo: aplicar una decisión con dos resultados: aprobado o no aprobado.

🧩 Conceptos

float, if, else, round()

Enunciado: pedir tres notas, calcular el promedio y decir si aprobó o no aprobó.

# Ejercicio 3: Nota final con if y else
nombre = input("Ingrese el nombre del aprendiz: ")
nota1 = float(input("Ingrese la nota 1: "))
nota2 = float(input("Ingrese la nota 2: "))
nota3 = float(input("Ingrese la nota 3: "))

promedio = (nota1 + nota2 + nota3) / 3

print()
print("=== RESULTADO ===")
print("Aprendiz:", nombre)
print("Promedio:", round(promedio, 2))

if promedio >= 3.5:
    print("Estado: Aprobado")
else:

Explicación:

  • float() se usa porque las notas pueden tener decimales.
  • El promedio se calcula sumando las tres notas y dividiendo entre 3.
  • round(promedio, 2) muestra el promedio con dos decimales.
  • else se ejecuta cuando la condición del if no se cumple.

4Promedio, asistencia y if-elif-else▾
▶ Abrir compilador Python en línea (Programiz) ↗ 📌 Escribe y ejecuta tu reto aquí si no tienes el programa instalado.

Objetivo: usar varias condiciones para clasificar el estado académico.

🧩 Conceptos

float, int, if, elif, else, and

Enunciado: calcular el promedio y revisar la asistencia; mostrar si aprueba, recupera, pierde por nota o por inasistencia.

# Ejercicio 4: Promedio, asistencia y if-elif-else
nombre = input("Ingrese el nombre del aprendiz: ")
nota1 = float(input("Ingrese la nota 1: "))
nota2 = float(input("Ingrese la nota 2: "))
nota3 = float(input("Ingrese la nota 3: "))
asistencia = int(input("Ingrese el porcentaje de asistencia: "))

promedio = (nota1 + nota2 + nota3) / 3

print()
print("=== REPORTE ACADÉMICO ===")
print("Aprendiz:", nombre)
print("Promedio:", round(promedio, 2))
print("Asistencia:", asistencia, "%")

if asistencia < 75:
    print("Estado: Perdió por inasistencia")
elif promedio >= 3.5 and asistencia >= 75:
    print("Estado: Aprobado")
elif promedio >= 3.0:
    print("Estado: Debe recuperar")
else:
    print("Estado: Perdió por nota")

Explicación:

  • Primero se valida la asistencia, porque afecta el resultado final.
  • elif revisa otras condiciones si la anterior no se cumplió.
  • and exige que se cumplan dos condiciones a la vez.
  • El else final cubre los casos restantes.

7Ficha con diccionario, conjunto y match-case▾
▶ Abrir compilador Python en línea (Programiz) ↗ 📌 Escribe y ejecuta tu reto aquí si no tienes el programa instalado.

Objetivo: integrar estructuras de datos y una condicional match-case.

🧩 Conceptos

dict, set, tuple, match-case, if anidado

Enunciado: guardar los datos en un diccionario, las evidencias en un conjunto y consultar con un menú.

# Ejercicio 7: Ficha del aprendiz (dict, set, match-case)
aprendiz = {
    "nombre": "María Torres",
    "grado": "10A",
    "ficha": 3441939,
    "promedio": 4.1,
    "activo": True
}
horario = ("Miércoles", "Viernes")
evidencias = {"Variables", "Condicionales", "Listas"}

print("=== MENÚ DE CONSULTA ===")
print("1. Ver datos del aprendiz")
print("2. Ver horario")
print("3. Ver evidencias entregadas")
print("4. Ver estado final")
opcion = int(input("Seleccione una opción: "))

match opcion:
    case 1:
        print("Nombre:", aprendiz["nombre"])
        print("Grado:", aprendiz["grado"])
        print("Ficha:", aprendiz["ficha"])
    case 2:
        print("Días de clase:", horario)
    case 3:
        print("Evidencias:", evidencias)
        if "POO" in evidencias:
            print("Ya entregó Programación Orientada a Objetos")
        else:
            print("Tiene pendiente Programación Orientada a Objetos")
    case 4:
        if aprendiz["activo"] and aprendiz["promedio"] >= 3.5:
            print("Estado: Activo y aprobado")
        else:
            print("Estado: Revisar situación académica")
    case _:
        print("Opción no válida")

Explicación:

  • Un diccionario guarda datos con clave y valor (nombre, grado, ficha).
  • Una tupla guarda datos que no se modifican, como los días de clase.
  • Un conjunto set evita datos repetidos.
  • match-case evalúa la opción de menú; case _ es la opción por defecto.

4. Introducción a la Programación Orientada a Objetos (POO)
🧩

Clases, objetos, atributos y métodos

Conceptos + ejercicios 8, 9 y 10

▾

La POO permite organizar el código usando clases y objetos. En vez de tener todo el programa en instrucciones sueltas, se crean moldes que representan elementos reales (por ejemplo, un estudiante, una actividad o una ficha).

ConceptoExplicación sencillaEjemplo
ClaseMolde o plantilla para crear objetos.class Estudiante:
ObjetoElemento creado a partir de una clase.estudiante1 = Estudiante(...)
AtributoCaracterística del objeto.self.nombre
MétodoAcción que puede realizar el objeto.calcular_promedio()
Constructor __init__Inicializa los atributos al crear el objeto.def __init__(self, nombre):
selfRepresenta el objeto actual dentro de la clase.self.nota1 = nota1
💡 Forma sencilla de explicarlo

Una clase es como un formulario vacío. Cuando lo llenamos con datos reales, creamos un objeto. Los datos del formulario son atributos y las acciones que puede hacer son métodos.

8POO 1: Clase Estudiante▾
▶ Abrir compilador Python en línea (Programiz) ↗ 📌 Escribe y ejecuta tu reto aquí si no tienes el programa instalado.

Objetivo: crear una clase con atributos, métodos y condicionales para obtener el estado académico.

🧩 Conceptos

class, __init__, self, atributos, métodos, if-else

Enunciado: clase Estudiante con nombre, grado y tres notas; calcula el promedio y muestra si aprobó o no.

# Ejercicio 8: POO 1 - Clase Estudiante
class Estudiante:
    def __init__(self, nombre, grado, nota1, nota2, nota3):
        self.nombre = nombre
        self.grado = grado
        self.nota1 = nota1
        self.nota2 = nota2
        self.nota3 = nota3

    def calcular_promedio(self):
        return (self.nota1 + self.nota2 + self.nota3) / 3

    def obtener_estado(self):
        promedio = self.calcular_promedio()
        if promedio >= 3.5:
            return "Aprobado"
        else:
            return "No aprobado"

    def mostrar_informacion(self):
        print("=== INFORMACIÓN DEL ESTUDIANTE ===")
        print("Nombre:", self.nombre)
        print("Grado:", self.grado)
        print("Promedio:", round(self.calcular_promedio(), 2))
        print("Estado:", self.obtener_estado())

estudiante1 = Estudiante("Laura Gómez", "10A", 4.0, 3.8, 4.5)
estudiante1.mostrar_informacion()

Explicación:

  • class Estudiante crea el molde para construir estudiantes.
  • __init__ recibe los datos iniciales; self.nombre, self.grado… son atributos.
  • calcular_promedio() y obtener_estado() son métodos (acciones).
  • estudiante1 es un objeto creado a partir de la clase.
🎯 Reto

Agrega un atributo asistencia y modifica obtener_estado() para que pierda si la asistencia es menor a 75.

9POO 2: Clase EntregaActividad▾
▶ Abrir compilador Python en línea (Programiz) ↗ 📌 Escribe y ejecuta tu reto aquí si no tienes el programa instalado.

Objetivo: representar una entrega académica como objeto y evaluar su estado.

🧩 Conceptos

class, bool, None, if-elif-else, métodos

Enunciado: clase que guarde la información de una actividad entregada e indique si está pendiente, a tiempo, tarde o aprobada.

# Ejercicio 9: POO 2 - Clase EntregaActividad
class EntregaActividad:
    def __init__(self, aprendiz, actividad, entregada, tarde, nota=None):
        self.aprendiz = aprendiz
        self.actividad = actividad
        self.entregada = entregada
        self.tarde = tarde
        self.nota = nota

    def obtener_estado(self):
        if not self.entregada:
            return "Pendiente por entregar"
        elif self.nota is None:
            return "Entregada, pendiente por calificar"
        elif self.tarde and self.nota >= 3.5:
            return "Aprobada, pero entregada tarde"
        elif self.nota >= 3.5:
            return "Aprobada"
        else:
            return "No aprobada"

    def mostrar_reporte(self):
        print("=== REPORTE DE ENTREGA ===")
        print("Aprendiz:", self.aprendiz)
        print("Actividad:", self.actividad)
        print("Entregada:", self.entregada)
        print("Entrega tarde:", self.tarde)
        print("Nota:", self.nota)
        print("Estado:", self.obtener_estado())

entrega1 = EntregaActividad("Carlos Pérez", "Condicionales", True, False, 4.2)
entrega1.mostrar_reporte()

Explicación:

  • La clase EntregaActividad representa una evidencia académica.
  • entregada y tarde son booleanos; nota=None = sin calificar.
  • not self.entregada verifica si no entregó; elif clasifica los estados.
🎯 Reto

Crea tres objetos diferentes: una entrega aprobada, una pendiente y una entregada tarde.

10POO 3: Clase Ficha con lista de aprendices▾
▶ Abrir compilador Python en línea (Programiz) ↗ 📌 Escribe y ejecuta tu reto aquí si no tienes el programa instalado.

Objetivo: usar una clase que contenga una lista de objetos y aplique condicionales para un reporte.

🧩 Conceptos

class, list, objetos, for, if, métodos

Enunciado: clase Ficha que guarde varios estudiantes, muestre cuántos tiene y liste quiénes están aprobados o en revisión.

# Ejercicio 10: POO 3 - Clase Ficha con lista de aprendices
class Estudiante:
    def __init__(self, nombre, promedio):
        self.nombre = nombre
        self.promedio = promedio

    def esta_aprobado(self):
        return self.promedio >= 3.5

class Ficha:
    def __init__(self, numero, programa):
        self.numero = numero
        self.programa = programa
        self.estudiantes = []

    def agregar_estudiante(self, estudiante):
        self.estudiantes.append(estudiante)

    def mostrar_reporte(self):
        print("=== REPORTE DE FICHA ===")
        print("Ficha:", self.numero)
        print("Programa:", self.programa)
        print("Cantidad de estudiantes:", len(self.estudiantes))
        for estudiante in self.estudiantes:
            if estudiante.esta_aprobado():
                estado = "Aprobado"
            else:
                estado = "En revisión"
            print(estudiante.nombre, "- Promedio:", estudiante.promedio, "-", estado)

ficha = Ficha(3441939, "Sistemas Teleinformáticos")

📝 Descripción del reto

Crear un programa en Python que permita registrar aprendices, actividades, notas, asistencia y estado de entrega. El programa debe generar un reporte final del aprendiz aplicando variables, tipos de datos, condicionales, listas, diccionarios y POO.

✅ Requisitos mínimos

1) Clase Aprendiz con nombre, grado, ficha, asistencia y lista de actividades. · 2) Clase Actividad con nombre, nota, estado de entrega y observación. · 3) Usar str, int, float, bool, list, dict, set, tuple y None. · 4) Usar if, if-else, if-elif-else y al menos una condicional anidada. · 5) Usar and, or y not. · 6) Crear mínimo tres objetos Aprendiz. · 7) Mostrar un reporte final con promedio, asistencia, actividades pendientes y estado académico. · 8) Agregar un menú con match-case (o if-elif-else si la versión no lo permite).

📋 Reglas del reto

Si promedio >= 3.5 y asistencia >= 75 → aprueba. · Si asistencia < 75 → en revisión por inasistencia. · Si tiene actividades pendientes → el reporte debe mostrarlas. · Si una actividad no tiene nota → se guarda con None y se muestra como pendiente por calificar. · Si no tiene actividades registradas → mostrar un mensaje de advertencia.
