Bienvenida a la Guía

De dividir una red a comprobar que funciona

▾

Cordial saludo, aprendiz.

En el RAP 01 usted aprendió a clasificar los tipos de redes, identificar topologías y aplicar el direccionamiento IP básico. La señora Carmen, dueña de la papelería que usted ayudó a conectar, ahora enfrenta un nuevo reto: abrió una sala de atención al público independiente de su oficina administrativa y quiere que cada zona tenga su propia red interna, sin perder la posibilidad de comunicarse entre ellas cuando sea necesario. Ese es exactamente el problema que resuelve la creación de subredes.

En esta guía usted desarrollará el RAP 02: comprobará la conectividad de una red aplicando conceptos de redes LAN y WAN, dividirá una red en subredes mediante cálculos de direccionamiento IP, y utilizará herramientas de validación como ipconfig, ping, tracert y nslookup para verificar que la red diseñada funciona correctamente. El resultado será la configuración y prueba de dos subredes en Cisco Packet Tracer.

5 ejercicios con procedimiento completo

3.3.1Taller de subneteo (Ejercicios 1–5)▾

Propósito: aplicar el método de subneteo de longitud fija (FLSM) para dividir una red en dos subredes, calculando correctamente rangos de host, dirección de red y de broadcast.

📐 Fundamentos del subneteo (FLSM) — procedimiento para dividir una red en 2 subredes iguales
  1. Determine cuántos bits necesita prestar para obtener el número de subredes requerido: con 1 bit prestado se obtienen 2 subredes (2¹ = 2).
  2. Sume ese bit a la máscara original: una red /24 (255.255.255.0) pasa a ser /25 (255.255.255.128) en cada subred.
  3. Calcule el “salto” entre subredes: 256 − 128 = 128, es decir, cada subred tiene 128 direcciones.
  4. Cada subred inicia en un múltiplo del salto (0, 128, 256…) y termina un número antes del siguiente múltiplo.
  5. La primera dirección de cada bloque es la dirección de red; la última es la dirección de broadcast; las intermedias son direcciones de host asignables.

Ejemplo guiado: red 192.168.20.0/24 dividida en 2 subredes:

  • Subred 1 (Ventas): 192.168.20.0/25 — Rango de host: 192.168.20.1 a 192.168.20.126 — Broadcast: 192.168.20.127
  • Subred 2 (Administración): 192.168.20.128/25 — Rango de host: 192.168.20.129 a 192.168.20.254 — Broadcast: 192.168.20.255

Resuelva los siguientes 5 ejercicios de forma individual, mostrando el procedimiento completo. Use como base la red 192.168.20.0/24.

EJERCICIO 1 — Calcular la nueva máscara

Si necesita dividir la red 192.168.20.0/24 en 2 subredes iguales, ¿cuántos bits debe prestar y cuál es la nueva máscara en notación decimal y en notación CIDR (/n)?

EJERCICIO 2 — Subred 1 (Ventas)

Determine para la Subred 1: dirección de red, primera IP utilizable, última IP utilizable y dirección de broadcast.

EJERCICIO 3 — Subred 2 (Administración)

Determine para la Subred 2: dirección de red, primera IP utilizable, última IP utilizable y dirección de broadcast.

EJERCICIO 4 — Asignación de IPs

Asigne una dirección IP válida de cada subred a los siguientes equipos, dejando la primera IP de cada subred para el gateway (router). Ventas: PC_Caja, PC_Venta1, PC_Venta2. Administración: PC_Gerencia, PC_Contable, PC_Bodega.

EJERCICIO 5 — Verificación en su equipo

Ejecute ipconfig /all en su computador, capture el resultado e indique en qué red y con qué máscara está configurado su equipo actualmente. Incluya la captura en el PDF que entrega.

3.4.1Laboratorio: dos subredes con verificación de conectividad▾

Propósito: aplicar de manera integral el direccionamiento por subredes y las herramientas de validación, configurando y comprobando la conectividad de una red en Cisco Packet Tracer. Recuerde: el objetivo principal no es solo construir la topología, sino comprobar y documentar que la conectividad funciona.

🖥 Escenario

La papelería de la señora Carmen necesita 2 subredes independientes: Ventas (caja y 2 puntos de atención) y Administración (gerencia, contabilidad y bodega), conectadas entre sí a través de un router para que Carmen pueda supervisar ambas desde su oficina.

Paso 1 — Diseño de la red

  1. Abra Cisco Packet Tracer y cree un nuevo proyecto.
  2. Agregue 1 Router (genérico) y 2 Switch 2960: uno para la subred Ventas y otro para la subred Administración.
  3. Agregue 3 PCs para Ventas: PC_Caja, PC_Venta1, PC_Venta2, y conéctelos al Switch de Ventas.
  4. Agregue 3 PCs para Administración: PC_Gerencia, PC_Contable, PC_Bodega, y conéctelos al Switch de Administración.
  5. Conecte cada Switch a una interfaz distinta del Router (GigabitEthernet0/0 con Ventas, GigabitEthernet0/1 con Administración) con cable recto (Copper Straight-Through).

Paso 2 — Configuración del direccionamiento IP

Asigne las direcciones calculadas en el taller de subneteo (Ejercicios 2 a 4) a cada dispositivo:

Paso 3 — Pruebas de conectividad

  1. Desde PC_Caja ejecute ping a PC_Venta1 (misma subred) y capture el resultado.
  2. Desde PC_Caja ejecute ping a PC_Gerencia (subred distinta, a través del router) y capture el resultado.
  3. Desde PC_Caja ejecute tracert a PC_Gerencia y verifique que el paquete pasa por el router (1 salto).
  4. En cada PC ejecute ipconfig y confirme que la dirección IP, la máscara y el gateway coinciden con la tabla de asignación.

Glosario de términos
📖

Glosario

Términos clave de la guía

▾
Subred (Subnet)
Porción de una red IP resultante de dividir un espacio de direccionamiento mayor mediante el préstamo de bits de host, delimitada por su propia dirección de red y de broadcast.
Subneteo (Subnetting)
Técnica de dividir una red IP en subredes más pequeñas ampliando la máscara de subred, con el fin de organizar, aislar y controlar el tráfico.
FLSM (Fixed Length Subnet Mask)
Método de subneteo en el que todas las subredes resultantes tienen el mismo tamaño (misma máscara).
VLSM (Variable Length Subnet Mask)
Método de subneteo que permite subredes de distinto tamaño según la cantidad de hosts requerida en cada una.
CIDR
Notación que expresa la máscara de subred como el número de bits en 1 (ej. /25).
Dirección de red
Primera dirección IP de una subred, usada para identificarla; no es asignable a un host.
Dirección de broadcast
Última dirección IP de una subred, usada para enviar tráfico a todos los hosts de esa subred; no es asignable a un host.
Rango de host
Conjunto de direcciones IP asignables a equipos dentro de una subred, ubicado entre la dirección de red y la de broadcast.
LAN (Local Area Network)
Red de área local que interconecta dispositivos en un espacio limitado (hogar, oficina, sede).
WAN (Wide Area Network)
Red que interconecta LANs distantes geográficamente, típicamente a través de un proveedor de servicios de telecomunicaciones.
DHCP
Protocolo que asigna automáticamente parámetros de red (IP, máscara, gateway, DNS) a los equipos cliente.
DNS (Domain Name System)
Sistema distribuido que traduce nombres de dominio a direcciones IP.
Proxy
Servidor intermediario que gestiona solicitudes entre clientes y otros servidores, aplicando control, filtrado o caché.
ICMP
Protocolo de control usado para mensajes de diagnóstico y error; herramientas como ping se basan en ICMP.
Ping
Herramienta de diagnóstico que verifica conectividad enviando mensajes ICMP Echo.
Tracert / traceroute
Herramienta que muestra la ruta (saltos) que siguen los paquetes hasta un destino.
Nslookup
Herramienta que consulta servidores DNS para verificar la resolución de nombres.
Ipconfig
Comando que muestra la configuración IP vigente de un equipo (dirección, máscara, gateway).
Gateway (puerta de enlace predeterminada)
Dirección del router por donde un equipo envía tráfico destinado a otras redes (fuera de su subred).
Captura de pantalla
Imagen de lo que se ve en la pantalla; en Windows se toma con las teclas Windows + Shift + S.
Packet Tracer
Simulador de redes de Cisco para diseñar, configurar y probar redes en el computador, sin usar equipos reales.
